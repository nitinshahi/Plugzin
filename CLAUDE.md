# Plugzin

Next.js 16 (App Router, Turbopack) + React 19 + TypeScript + Tailwind v4 + shadcn/ui.
Frontend only for now — no backend, no payments. Desktop-only layouts; the Figma
has no mobile frames yet.

## Rules

- **Never use arbitrary Tailwind values** (`bg-[#fff]`, `p-[13px]`, `text-[15px]`).
  Only theme tokens. If a token is missing, STOP and ask.
- **Server Components by default.** `'use client'` only for state, effects or handlers.
- **No new dependencies without asking.**
- **No inline styles, no CSS modules.**
- Don't add comments that restate the code.
- Don't add error handling for cases that can't happen yet.
- Don't refactor or improve files you weren't asked about.
- Don't write tests unless asked.

## Tokens

Defined in `src/app/globals.css`. Brand tokens are declared in `@theme inline`
and given values on `:root`; the shadcn semantic tokens point at them so
`npx shadcn add` keeps inheriting the brand. The site is dark-only — there is no
light mode and the `.dark` class is unused.

## Fonts

`src/lib/fonts.ts`. Three faces, all served from `src/fonts/web/*.woff2`:

- `font-display` — Helvetica Black Condensed. Headings, nav, button labels.
- `font-helvetica` — Helvetica 400/700. Hero copy, pills, footer.
- `font-sans` — Inter. Plugin cards and testimonials.

The licensed originals in `src/fonts/*.otf|ttf` are **misnamed**: every file holds
the face named by a different filename, and several "upright" names are oblique
cuts. The three in use were identified by measuring stem thickness and the `n`
advance width. Re-run that measurement before swapping any of them.

## Icons

`lucide-react`. Only real brand artwork is exported from Figma to `public/brand`.

## Data

`src/data/*.ts`, typed by `src/types/plugin.ts`. Pages read through the helper
functions, never the arrays, so a CMS or API can replace them in one file.

## Exceptions to the no-arbitrary-values rule

`src/components/ui/button.tsx` is generated by shadcn and is left as vendored
code; re-running `npx shadcn add` would overwrite edits anyway. Everything else
under `src/` is free of arbitrary values and inline styles.

Values that Tailwind can't express are named utilities in `globals.css`:
`font-display`, `bg-gradient-brand`, `btn-shape-primary`, `btn-shape-outline`,
`transition-filter`.

Tailwind v4 generates `max-w-124` and `h-70` from the spacing scale but **not**
decimals — `pt-22.75` and `left-156.5` silently produce nothing. Off-grid values
are snapped to the nearest 4px step or given a token.

## Gotchas

- The dev server does not always pick up `@theme` changes. If a new token seems
  to have no effect, restart it before debugging the token.
- shadcn's `Button` sets `font-medium`; tailwind-merge doesn't treat that as the
  same concern as `font-display`, so pair the two with an explicit `font-black`.
